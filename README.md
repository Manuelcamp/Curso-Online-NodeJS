# 🖥 Curso Online de Node.JS

Olá! Seja bem-vindo ao meu repositório inicial do **Curso Online de Node.JS**.

Este repositório consiste nas aulas iniciais de fundamentos. Todas as seções e módulos estão documentados sobre o que se trata cada uma, assim como cada código apresentado.

Por este ser meu segundo repositório de linguagem de programação, estou me esforçando para que seja o mais **detalhado, limpo e constante** possível, para que pessoas de fora possam ver, aprender e entender com ele.

É isso, até mais! 👋
